## Featured projects

### 🚤 Maritime Rescue Simulator — Development Project
Further development of a maritime rescue training simulator, focusing on real-time data visualization and hardware integration. The project involved building a data pipeline connecting Signal K, InfluxDB, and Grafana with Raspberry Pi and Arduino hardware.

- **Technologies:** Python, Signal K, InfluxDB, Grafana, Raspberry Pi, Arduino, NMEA 0183
- **Focus:** Real-time data, IoT, data visualization, hardware integration
- [Read the project thesis on Theseus](https://www.theseus.fi/server/api/core/bitstreams/ba17ba91-562e-4e6f-b21d-312e31e3e5aa/content)

- **Technologies:** JavaScript, Express.js, EJS, CSS

- **Technologies:** Python, Jupyter Notebook, pandas
